Shell spec

  • Sidebar: white bg, 52px collapsed / 200px expanded on group-hover, CSS transition 200ms ease. No JS required.
  • Active item: bg-blue-50 border border-blue-200 text-blue-700. Inactive: text-slate-500 hover:bg-slate-50.
  • Logo: Blue 30px square with "S" monogram, collapses to icon-only.
  • Nav items: Dashboard, Sites, Invoices, Customers, Reports, Reservations — Settings pinned at bottom.
  • Content area: bg-slate-50, scrollable, p-8 padding.
  • Top-right: Avatar/user menu (no topbar — sidebar handles all nav).
